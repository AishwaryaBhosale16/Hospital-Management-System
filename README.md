🏥 Hospital Management System
A Java-based console application that helps manage hospital records efficiently.
It is a beginner-friendly project that demonstrates the use of Object-Oriented Programming (OOP) principles like Encapsulation, Abstraction, and toString() overriding.
This project allows hospital staff to add, view, and delete patients as well as book, view, and cancel appointments.

✨ Features
👤 Patient Management
➕ Add new patients with details (ID, Name, Age, Disease)
🔍 View all registered patients
❌ Delete patient record by ID (also deletes their appointments automatically)

📅 Appointment Management
📌 Book appointments for existing patients
📖 View all booked appointments
🚫 Cancel appointments by Patient ID

🛠️ Tech Stack
Language: Java (JDK 8 or above)
Data Structures: ArrayList for in-memory storage
Concepts Used:
Classes & Objects
Encapsulation
ArrayList Operations
Method Overriding (toString())
Switch-case driven menu system

#Project Structure :- 
Hospital-Management-System/
│

├── HospitalManagementSystem.java    # Main class with menu-driven system
└── README.md                        # Documentation

🎯 Use Cases
Hospitals or clinics can use this system to track patients and appointments.
Useful for students learning Java OOP concepts.
Can be extended into a full-stack hospital management application.

📘 Learning Outcomes
By working on this project, you will learn:
✔ How to implement OOP concepts in Java
✔ How to use ArrayLists for managing records
✔ How to design a menu-driven application
✔ Basics of CRUD operations (Create, Read, Update, Delete)
