# 🏥 Hospital Management System  

A **Java-based console application** for managing hospital records.  
This project demonstrates **Object-Oriented Programming (OOP)** concepts and provides features to manage **patients** and their **appointments** efficiently.  

---

## ✨ Features  

### 👤 Patient Management  
- ➕ Add new patients (ID, Name, Age, Disease)  
- 🔍 View all patients  
- ❌ Delete patient records (appointments are also deleted automatically)  

### 📅 Appointment Management  
- 📌 Book appointments for patients  
- 📖 View all appointments  
- 🚫 Cancel appointments  

---

## 🛠️ Tech Stack  

- **Language:** Java (JDK 8 or higher)  
- **Data Structures:** ArrayList  
- **Concepts Used:**  
  - Classes & Objects  
  - Encapsulation  
  - ArrayList operations  
  - Method Overriding (`toString()`)  
  - Switch-case driven menu system  

---

## Usage

1. Run the application to open the system interface.
2. Use the menu options to:
   - **Add a patient**: Enter patient details to store a new record.
   - **Search a patient**: Find patient records by ID or name.
   - **Update a patient**: Modify existing patient details.
   - **Delete a patient**: Remove patient records.
   - **Display all patients**: View all stored patient records.
